# NWN VFX Studio scope

This project and its task handle VFX authoring, browser preview and resource
export. Do not launch or control Aurora Toolset or Neverwinter Nights here.
Do not perform native module installation, MOD/HAK integration or native proof
work from this task. A consumer task performs integration and game testing
directly through its qualified Aurora tools. Export/readback alone is never
native validation. Use isolated fixtures or explicit forks for feature tests;
preserve accepted user projects and their artifacts.
